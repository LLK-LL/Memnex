# v12.5.0 - Memory graph visualization

## What is included

- Adds a local memory galaxy viewer export tool.
- Exports graph nodes, edges, type counts, weights, and linked knowledge summaries into a static `graph.json`.
- Ships browser assets for a draggable 2D galaxy and a 3D spherical galaxy.
- Reads the memory database in SQLite read-only mode and writes only to the chosen export directory.
- Keeps real memory data out of the repository and release artifacts.

## Who should try it

Use this release if you want to inspect how concepts, projects, facts, lessons, and knowledge records connect inside a Total Agent Memory database without uploading private memory content anywhere.

## How to use

```bash
python src/tools/memory_graph_viewer_export.py --output /tmp/tam-graph-viewer
```

Then open `index.html` in the output directory. Use `--db`, `--max-nodes`, `--max-edges`, and `--min-edge-weight` when you want to inspect a specific database or produce a smaller graph.

## Memory Galaxy Views

Open `index.html` for the 2D Memory Galaxy view. This is the default exploration surface: a draggable local star map with search, type filters, galaxy-layer filters, timeline filtering, selected-node details, provenance/source display, and local agent prompt stubs.

This document describes the original v12.5.0 surface. In v12.6.0, the viewer
also ships the 2D/3D coexistence bridge and Knowledge Solar System route. See
[`v12.6.0-visual-memory-release.md`](v12.6.0-visual-memory-release.md) for
the current panel, operation, gesture, and 3D integration guide.

Both views use a default visible-node budget to stay responsive. Full graph exploration should be treated as an advanced mode for powerful browsers, not the default.

The viewer exports cache metadata with the default cache root:

```text
D:\TotalAgentMemory\memory-galaxy-cache
```

The browser viewer remains static and local. Interaction events such as node selection, dragging, expansion, and filtering are normalized in the browser so future voice or agent adapters can react to them, but this release does not call external APIs or write to the memory database.

## Privacy boundary

This release contains only system files: source code, tests, scripts, docs, and static viewer assets. It does not include live memory databases, WAL/SHM files, logs, transcripts, raw captures, backups, or exported private memory content.

## Current limitations

- The viewer is a local static export, not a hosted service.
- Large graphs may need `--max-nodes` or `--min-edge-weight` for smoother browser rendering.
- The exported `graph.json` can contain summaries from the selected local memory database, so keep generated viewer output private unless you have reviewed it.
